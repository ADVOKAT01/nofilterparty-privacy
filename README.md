# No Filter Party — страница политики конфиденциальности

Готовые файлы сайта для GitHub Pages. Сайт **НЕ опубликован автоматически**.

## Как опубликовать за несколько минут

1. Открой https://github.com/new и войди в свой аккаунт GitHub.
2. В поле **Repository name** введи `nofilterparty-privacy`.
3. Выбери **Public**. Не включай автосоздание README, чтобы загрузить наши файлы сразу.
4. Создай репозиторий (`Create repository`).
5. Нажми **uploading an existing file** (или `Add file` → `Upload files`).
6. Перетащи сюда файлы `index.html`, `privacy-en.html` и `.nojekyll` (последний необязателен). `README.md` тоже можно загрузить.
7. Нажми `Commit changes` в ветку `main`.
8. Перейди `Settings` → `Pages` → `Build and deployment` → `Source: Deploy from a branch` → `main` → `/(root)` → `Save`.
9. Открой появившуюся кнопку **Visit site**. Адрес обычно будет вида `https://ИМЯ_ПОЛЬЗОВАТЕЛЯ.github.io/nofilterparty-privacy/`.
10. Открой ссылку в режиме инкогнито и на телефоне. Проверь русский/английский переключатель и email.
11. Только после проверки вставляй этот URL в RuStore. В игре локальная политика должна иметь ту же актуальную редакцию.

**Важно:** не загружай в публичный репозиторий исходники игры, токены, пароли, keystore, APK, личные документы, приватные заметки.

## Что ещё подтвердить перед объявлением политики окончательной

- Провести аудит именно **финального production APK**, а не только отчётов debug-сборки.
- Убедиться, что в нём отсутствуют реклама, аналитика, отправка данных и разрешение INTERNET (или обновить политику, если появятся).
- Проверить фактические настройки резервного копирования, удаление локальных данных и поддержку почтовых обращений.
- Проверить, достаточно ли идентификации разработчика как физического лица с рабочим email для актуальных правовых требований; при необходимости дополнить политику сведениями владельца непосредственно перед публикацией.
- Утвердить текст владельцем, не выдавать черновик за юридически проверенный документ.

Этот сайт подготовлен по отчётам проекта о локальной офлайн-версии. Точная работа будущих релизов требует отдельного подтверждения.
